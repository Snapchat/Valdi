# Getting Help with Valdi

## Documentation

- The [Valdi documentation](./docs/README.md) covers installation, guides, and API reference.
- The [troubleshooting guide](./docs/docs/help-troubleshooting.md) and [FAQ](./docs/docs/faq.md) answer the most common setup and build questions.
- `valdi doctor` checks your development environment for common problems.

## Questions

For questions about using Valdi, please start a thread in [GitHub Discussions](https://github.com/Snapchat/Valdi/discussions). The community and maintainers answer questions there, and the answers help others with the same question.

GitHub Issues is reserved for bug reports and planned work, so questions opened as issues will be redirected to Discussions.

## Bug reports

If you have found a bug, please open an issue using the [bug report form](https://github.com/Snapchat/Valdi/issues/new/choose) and include the steps needed to reproduce it.

## Security

Please report security vulnerabilities privately through [HackerOne](https://hackerone.com/snapchat). See [SECURITY.md](./SECURITY.md).

## Response times

Valdi is maintained by a small team, and support in Discussions and Issues is provided on a best-effort basis. We read everything, but we cannot guarantee a response time.
