# Maintainers

Valdi is maintained by the Valdi team at Snap Inc. The team reviews and approves all changes to the project, as described in [GOVERNANCE.md](./GOVERNANCE.md).

## Contacting the maintainers

- **Questions and ideas:** [GitHub Discussions](https://github.com/Snapchat/Valdi/discussions)
- **Bug reports:** [GitHub Issues](https://github.com/Snapchat/Valdi/issues/new/choose)
- **Security vulnerabilities:** please report privately through [HackerOne](https://hackerone.com/snapchat), not in a public issue or discussion.

Please avoid contacting individual maintainers directly about issues or pull requests. Using the public channels above makes sure your request reaches whoever is best placed to help.
